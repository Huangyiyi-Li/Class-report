## 2026-03 最新更新: 统一报告生成模块
### 核心改进
1. **单一页面结构**: 将原本两步注入的长且容易变形的报告改为一体化的HTML结构。
2. **侧边栏导航**: 引入了响应式左侧固定导航栏，方便跳转。
3. **定制打印导出**: 集成了自动样式处理、分页防截断及各分析模块按需求选择呈现然后导出至 PDF。
4. **图表集中初始化**: 所有的 ECharts 图表 (包括饼图、力导向图、雷达图、文字云、柱状图等) 用统一的 `data` 注入和 `IIFE` (立即执行函数) 管理加载。

### 主要文件
* `auto_analyze_simple.py`: 报告生成命令行工具，负责自动读取目录、启动两次大模型并发分析（基础与扩展），以及自动组装单一HTML。
    * **使用方法**: `python auto_analyze_simple.py "目录路径"`
* `icas_report_extended.py`: 最新版综合分析报告主模块，替代了原有的片段式组合方式。负责产出最终的带 UI 的报告代码。
* `PRD/ICAS_REPORT_REDESIGN_PRD.md`: 新报告生成机制的设计与实现文档。
