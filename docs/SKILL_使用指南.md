# 课堂录音分析Skill - 使用指南

## 🎯 设计理念

主人告诉浮浮酱分析哪次课,浮浮酱自动完成一切! 🚀

## 📁 文件夹准备

### 步骤1: 创建文件夹
```
你的课堂录音/
├── 第一次课/
│   ├── recording.xlsx      (录音转录Excel)
│   └── lesson_plan.docx    (教案,可选)
├── 第二次课/
│   └── transcript.txt      (录音转录文本)
└── 第三次课/
    ├── recording.xlsx
    └── design.txt          (教案文本)
```

### 步骤2: 放入文件

**录音文件** (必需):
- Excel文件 (`.xlsx`, `.xls`) - 自动读取F列
- 文本文件 (`.txt`) - 直接粘贴转录文本

**教案文件** (可选):
- Word文件 (`.docx`, `.doc`)
- 文本文件 (`.txt`)

## 💡 使用技巧

### 技巧1: 文件夹命名
文件夹名称可以自由定义,方便识别:
- `第一次课`
- `第三章_函数`
- `张老师_20260110`
- `公开课实录`

### 技巧2: 教案很重要
虽然教案是可选的,但提供教案可以:
- ✅ 获得"教学设计契合度评价"
- ✅ 对比预设目标与实际授课
- ✅ 发现生成的精彩瞬间

### 技巧3: 批量处理
创建批处理文件 `analyze_all.bat`:
```batch
@echo off
python ../auto_analyze_simple.py 第一次课
python ../auto_analyze_simple.py 第二次课
python ../auto_analyze_simple.py 第三次课
echo 全部完成!
pause
```

## ⚙️ 技术细节

**脚本位置**: `ICAS_AI/auto_analyze_simple.py`

**运行命令**:
```bash
cd ICAS_AI
python auto_analyze_simple.py "第一次课"
```

**文件夹结构要求**:
- 脚本会在当前目录的子文件夹中查找
- 例如: 当前在 `ICAS_AI/`,则查找 `ICAS_AI/第一次课/`

**文件识别优先级**:
- 录音: `.xlsx` > `.xls` > `.txt`
- 教案: `.docx` > `.doc` > `.txt`

## 🆘 常见问题

### Q: 找不到文件夹?
A: 确保文件夹在 `ICAS_AI/` 目录下

### Q: 找不到录音文件?
A: 检查文件格式是否为 `.xlsx`, `.xls` 或 `.txt`

### Q: Excel文件读取失败?
A: 确保Excel有F列,并且F列包含转录文本

### Q: 如何保存PDF?
A: 在浏览器中按 `Ctrl+P`,选择"另存为PDF"

### Q: 可以自动转PDF吗?
A: 当前版本需要手动保存PDF,但浮浮酱会自动打开报告方便操作
