# 课堂录音采集助手 v0.2.0-codex.36

**构建失败，未发布。** Windows 打包界面检查发现原生视口高度为 39px，与请求的 24px 不同；`100vh` 布局会随之变厚。请使用后续候选版本。

本候选原计划减少录音客户端对课件和白板操作的遮挡。

- 已配置的客户端默认在系统托盘运行；首次部署仍打开配置界面。
- 悬浮窗按需开启，改为 88×24 DIP 圆角胶囊，保留录音状态、拖动和直接隐藏按钮。
- 隐藏仅影响悬浮窗显示，不改变录音状态；关闭主窗口后不会再次弹出。显示选择在配置数据目录后保存，重启仍生效。
- 首次隐藏说明如何从托盘找回。开始、暂停、恢复和采集故障提供状态提示；同一持续故障不反复提醒，上传进度和断网补传不触发采集中断提示。
- Windows 窗口采用不透明背景及同尺寸原生胶囊裁剪，移除旧圆球白色高光和外围透明圈；首帧绘制后显示，降低白边、闪白风险。

## 验证与限制

- 本地 Node 218 项通过；Python 233 项通过、1 项跳过；前端构建及 Mac Electron 源码窗口检查通过。
- Windows CI 执行 Python/Node 检查、Passport 回归、worker 构建、NSIS/Portable 打包、资源验证、打包界面烟测和真实 packaged worker 正常启动门禁。结果以对应 Actions 为准。
- **Windows 10/11 真机圆角边缘、100%/125%/150% 缩放、失焦白边、白板触摸尚未验收。原生裁剪可能有整数边缘锯齿，不能宣称现场白边已彻底修复。**
- 系统通知可能被 Windows 勿扰或通知设置抑制；仍可从托盘及主窗口查看状态。便携版通知表现需单独验证。
- 本版不代表真实麦克风、长时间录音、生产上传和学校现场验收已完成；此前上传凭证问题不在本次修复范围。

日常试用优先下载 Setup 安装版；Portable 用于临时免安装测试。已有用户升级前请停止录音。
