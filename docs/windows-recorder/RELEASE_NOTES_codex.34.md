# 课堂录音采集助手 v0.2.0-codex.34

本候选版本改善日常使用中的说明、设置和诊断体验。

- 录音说明默认收起，主动点击才展开，重启或状态刷新不会自动展开。
- 普通模式隐藏高级设置并限制接口地址修改；技术维护可通过进程环境变量 `RECORDER_MAINTENANCE_MODE=1` 开启。
- 后台每分钟自动保存录音和上传诊断快照至录音数据目录 `logs/diagnostics`。近 7 天按日期保留，每天最多两个 2 MiB 文件，敏感字段脱敏，写入失败不会停止录音。普通设置页提供打开日志文件夹入口。
- 最近录音直接显示保存、上传结果；取消无法操作的“请核对有效时段”，完整性补充说明默认折叠，已确认的文件缺失和保存未完成仍明确展示。

## 验证与已知限制

- 本地 Python：233 项通过、1 项跳过；Node：208 项通过；渲染构建、页面展开/收起/重载及日志入口检查通过。
- Windows 打包、资源检查、安装包启动检查由本次 Release CI 执行，结果以对应工作流为准。
- 上传凭证获取失败尚未确认解决；此版本未宣称修复该问题。
- 自动日志记录后台录音和上传状态；Passport 登录窗口事件仍通过维护模式手动导出诊断获取。
- 本版本为预发布候选，尚不代表真实 Windows 麦克风、长时间录音和学校现场验收完成。

安装建议：日常使用下载 Setup 安装包；Portable 用于便携测试。
