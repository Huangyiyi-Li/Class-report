## 使用变化

1. 首次展示录音用途、数据去向、启停方式与三步开始说明。点击“知道了”后，在已有非系统盘配置中保存阅读版本；尚未配置目录时只收起本次说明。右上角“录音说明”图标始终可再次打开。说明不会停止正在进行的录音，也不改变原有自动录音默认值。
2. 设置中的麦克风选择下新增 8 秒试录、输入音量和回放。使用当前下拉框选择的设备；选择设备后仍需保存设置，才能用于后续正式录音。测试不会自动停止正在进行的正式录音；用户可以点击“停止正式录音”后再测试。
3. 主界面显示最近三次录音的起止时间、本地保存情况、上传与登记结果。暂停后继续属于同一次录音；停止后再次开始产生新记录。没有课表匹配，不将一次录音称作“一节课”。

## 结果与数据边界

- 只有录音已结束、存在片段、所有片段上传并登记成功、且没有已知中断或待保存片段时，才显示整次完成。
- 正在录制的尾段尚未生成文件是正常状态，不因此提示中断。
- 麦克风异常、恢复录音失败、worker 非正常退出或缺失片段保留核对提示。worker 重启后不能确认精确结束时间时，显示“结束时间未确认”。
- 停止后重复停止不更新原结束时间。网络恢复后成功补传，结果跟随队列状态更新。
- 旧录音缺少会话标识，不推断或补造历史记录。旧队列继续按原流程处理。
- 新增 `recording_runs` 和 `recording_run_segments` 两张本地表，不增加旧 segments 表的字段，也不改变服务端音频登记载荷。音频 journal 带会话标识，断电恢复后仍可关联记录。
- 试录采用与正式录音一致的 PortAudio 输入方式（16 kHz、单声道、16 bit），最多保留 8 秒 PCM。文件不落盘，不创建 journal，不进入上传队列。通过受限本机控制通道返回 WAV 供临时回放，不放入广播快照或诊断包。
- 切换设备、结束并清除、关闭设置时清除临时回放。即使界面异常关闭，worker 仍在 8 秒自动结束采集，并在 60 秒清除剩余试录内存；正常取回后立即清除 worker 副本。
- 音量不代替试听，也不判断是否有人声。权限提示按实际平台与学校配置描述，不承诺“只有本人和管理员可见”。

## 本地验证

- Python：录音会话隔离、25 个片段完整汇总、登记前不报成功、重新打开数据库、暂停继续、故障恢复、试录容量、流释放、正式录音互斥、试录不落盘不进队列、说明持久化。
- Node：完成状态、中断/缺失/空录音、正常录制尾段判断，以及原有回归和打包依赖检查。
- Vite：生产构建。
- 浏览器：模拟 IPC 与合成音频，检查首次说明、最近录音、音量条、回放、换设备清除、正式录音时禁用测试，以及 1024×640 / 880×560 布局。截图位于本地 `electron-recorder/output/playwright/`。这些不是 Windows 录音或真实上传证据。
