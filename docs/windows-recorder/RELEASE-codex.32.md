# v0.2.0-codex.32

Windows 10/11 x64 内部测试版。

## 修复

- 适配公司首页域名迁移：识别 szjx.xinzx.cn，登录跳转后读取学校身份并自动关闭 Passport 窗口。
- 保留跨 Electron 隔离边界的错误字段：手动关闭登录窗口时，页面与诊断均显示 BIND-C01，避免错误显示为 BIND-C99；同时保留业务错误码及部分解绑状态。

## 验证

- 本地 Node 206 项测试、构建及真实 Electron 回归通过。
- Windows CI 增加错误字段跨隔离边界、首页 301 跳转两项回归；实际执行结果以本标签 Actions 为准。
- Release 提供 Setup、Portable、codex.yml 和更新 blockmap。

## 安装后复测

1. 完全退出客户端后启动，发起绑定并登录、选择学校，确认首次即可自动关闭 Passport 并进入绑定选择。
2. 主动取消登录，核对页面和诊断均为 BIND-C01。
3. 完成绑定后录音、停止，确认原有数据及配置保留。

自动化导航使用模拟身份，不代表真实 Windows 账号首次登录及麦克风已验收。现场复测仍待完成。
