# 课堂录音处理技能

## 技能描述

智能课堂录音一体化处理工具，整合两大核心功能：
1. **🤖 AI教学分析**：深度分析课堂录音，生成专业教学诊断报告
2. **🎵 音频处理**：从Excel下载音频链接，转换为高质量MP3并合并

主人可以灵活选择执行单个功能或完整处理流程。

## 核心功能

### 🤖 AI教学分析
- 🔍 **智能识别**：自动扫描文件夹中的录音和教案
- 📊 **多维度评估**：时间分配、五维能力、认知层次、反馈质量
- 📄 **双格式报告**：HTML（可交互）+ PDF（可直接打印）
- 🌐 **浏览器预览**：自动打开HTML报告
- 📈 **可视化图表**：雷达图、饼图、知识图谱等

### 🎵 音频处理
- 📥 **智能下载**：从Excel批量下载音频文件
- 🎵 **顶级音质**：320kbps CBR + 48kHz立体声
- 🔗 **自动合并**：按顺序拼接为完整文件
- 📊 **实时进度**：全程可视化处理进度
- ✅ **容错处理**：自动跳过失败文件

## 文件夹准备

主人需要准备课程文件夹，包含以下文件（按需）：

```
第七次课0318/
├── 语文-7段-0918-0948.xlsx      # 录音文件或音频链接表
│                                 # (F列=转录文本 或 file_path列=音频链接)
├── 《中国美食》教学设计.docx     # 教案文件（可选）
└── 其他文件...
```

**支持格式**:
- 录音/音频: `.xlsx`, `.xls` (自动识别F列或file_path列), `.txt`
- 教案: `.docx`, `.doc`, `.txt`

**Excel格式说明**:
- **AI分析模式**：需要F列包含课堂转录文本
- **音频处理模式**：需要`segment_index`和`file_path`列
- **完整处理模式**：可以同时包含两列

## 执行步骤

浮浮酱会根据主人的需求执行相应步骤：

### 🤖 AI分析流程
1. **扫描文件**：识别录音文件（Excel的F列）
2. **读取内容**：提取转录文本和教案
3. **AI深度分析**：调用火山引擎Doubao进行多维度分析
4. **生成报告**：创建HTML和PDF格式
5. **打开预览**：在浏览器中显示HTML报告

### 🎵 音频处理流程
1. **读取Excel**：从file_path列提取音频链接
2. **批量下载**：下载所有音频文件
3. **格式转换**：使用ffmpeg转换为320kbps MP3
4. **智能合并**：按segment_index顺序拼接
5. **输出文件**：生成完整的MP3文件

### 🎯 完整处理流程 ⭐
1. **扫描文件夹**：识别所有可用文件
2. **并行处理**：同时执行AI分析和音频处理
3. **生成结果**：分析报告 + 完整音频
4. **统一预览**：浏览器打开报告，提供音频路径

## 注意事项

### 文件格式
- ⚠️ Excel文件必须包含相应列（F列或file_path列）
- ⚠️ 音频处理需要segment_index列（从1开始连续编号）
- ✅ 支持中英文路径和文件名

### 系统要求
- ⚠️ 首次使用需安装依赖包
- ⚠️ PDF生成需要Playwright（首次需下载Chromium）
- ✅ 确保有足够磁盘空间（至少是音频文件大小的3倍）

### 网络要求
- ⚠️ 音频下载需要稳定的网络连接
- ⚠️ AI分析需要访问火山引擎API
- ✅ 自动重试失败的下载

## 智能特性

### 自动模式识别
浮浮酱会根据Excel内容智能判断处理模式：
- 仅F列有内容 → AI分析模式
- 仅file_path列有内容 → 音频处理模式
- 两列都有内容 → 完整处理模式

### 并行处理优化
完整处理模式下，AI分析和音频处理并行执行，大幅提升效率。

### 错误自动恢复
- 下载失败 → 自动跳过，继续处理其他文件
- 转换失败 → 记录错误，不影响整体流程
- 分析失败 → 提供详细错误信息
