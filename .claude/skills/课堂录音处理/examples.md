2. **使用标准模板**：
   ```
   | segment_index | file_path           | ... | F列       |
   ```

3. **删除多余空格**：

   - 使用精确的列名

### Q3：PDF生成失败

**问题**：`'gbk' codec can't encode character`

**原因**：HTML中的emoji字符无法用GBK编码

**解决**：

1. **手动保存PDF**：
   - 在浏览器中打开HTML报告
   - 按 `Ctrl+P`
   - 选择"另存为PDF"

2. **移除emoji**（修改脚本）：
   ```python
   # 在生成HTML时移除emoji
   content = content.replace('✅', '[OK]')
   content = content.replace('⚠️', '[WARN]')
   ```

3. **使用UTF-8编码**（修改脚本）：
   ```python

   page.pdf(
       path=output_pdf,
       encoding='utf-8'
   )
   ```

### Q4：ffmpeg找不到

**问题**：`FileNotFoundError: ffmpeg`

**解决**：

2. **添加到PATH**：

   ```bash
   # Linux/Mac
   export PATH=$PATH:/usr/local/bin
   ```

3. **验证安装**：
   ```bash
   ffmpeg -version
   ```

### 示例14：添加元数据

**需求**：为MP3添加标签信息

```python
def add_metadata(output_file, course_name, date):
    """添加ID3标签"""
    from mutagen.mp3 import MP3
    from mutagen.id3 import ID3, TIT2, TPE1, TALB

    audio = MP3(output_file, ID3=ID3)
    audio.tags.add(TIT2(encoding=3, text=f"{course_name}课堂录音"))
    audio.tags.add(TPE1(encoding=3, text="濮东老师"))
    audio.tags.add(TALB(encoding=3, text="课堂录音系列"))
    audio.tags.add(
        ID3.get_frame('TCON')(encoding=3, text="教学")
    )
    audio.save()
```

### 示例15：生成播放列表

**需求**：创建M3U播放列表

```python
def generate_m3u(output_dir, filename, files):
    """生成M3U播放列表"""
    m3u_path = os.path.join(output_dir, f"{filename}.m3u")

    with open(m3u_path, 'w', encoding='utf-8') as f:
        f.write("#EXTM3U\n")
        for file_info in files:
            duration = file_info.get('duration', -1)
            name = file_info.get('name', 'Unknown')
            path = file_info['path']

            f.write(f"#EXTINF:{duration},{name}\n")
            f.write(f"{path}\n")

    return m3u_path
```
