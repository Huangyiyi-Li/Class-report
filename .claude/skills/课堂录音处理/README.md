# 课堂录音处理 Skill 🎓

> 智能课堂录音一体化处理工具 - AI分析 + 音频处理，一步到位！

## ✨ 功能亮点

### 🤖 AI教学分析
- 🔍 **一键分析**：自动识别录音文件，智能教学诊断
- 📊 **多维度评估**：时间分配、五维能力、认知层次、反馈质量
- 📄 **双格式报告**：HTML（可交互）+ PDF（可直接打印）
- 🌐 **浏览器预览**：自动打开HTML报告
- 📈 **可视化图表**：雷达图、饼图、知识图谱等

### 🎵 音频处理
- 📥 **智能下载**：从Excel批量下载音频文件
- 🎵 **顶级音质**：320kbps CBR + 48kHz立体声
- 🔗 **自动合并**：按顺序拼接为完整文件
- 📊 **实时进度**：全程可视化处理进度

### 🎯 完整处理 ⭐
- ⚡ **并行执行**：AI分析和音频处理同时进行
- 🚀 **高效优化**：完整处理仅需2-3分钟
- 📦 **一次搞定**：分析报告 + 完整音频

## 🎯 支持的文件格式

### 录音/音频文件（必需）
- **Excel**: `.xlsx`, `.xls`
  - AI分析模式：自动读取 F 列（转录文本）
  - 音频处理模式：读取 `segment_index` 和 `file_path` 列
  - 完整处理模式：同时支持两列
- **文本**: `.txt` - 直接粘贴转录文本

### 教案文件（可选）
- **Word**: `.docx`, `.doc`
- **文本**: `.txt`

## 📊 Excel文件格式说明

### AI分析模式
需要F列包含课堂转录文本：

| A列 | B列 | ... | F列 |
|-----|-----|-----|-----|
| ... | ... | ... | 学生：老师好... |

### 音频处理模式
需要`segment_index`和`file_path`列：

| segment_index | file_path |
|---------------|-----------|
| 1 | https://example.com/audio1.m4a |
| 2 | https://example.com/audio2.m4a |

### 完整处理模式 ⭐
可以同时包含两种列，同时进行AI分析和音频处理。

## ⚙️ 系统要求

### 必需软件
- **Python**: 3.7 或更高版本
- **ffmpeg**: 用于音频转换和合并（已包含在项目中）
- **Chromium**: 用于PDF生成（自动下载）

### Python依赖
```bash
# 安装所有依赖
pip install pandas requests tqdm openpyxl playwright

# 安装Playwright浏览器
playwright install chromium
```

**依赖说明**:
- `pandas` - 读取Excel文件
- `requests` - HTTP下载
- `tqdm` - 进度条显示
- `openpyxl` - Excel文件支持
- `playwright` - PDF生成

### API要求
- 火山引擎API密钥（已内置，无需配置）

## 🔄 工作流程

### 仅AI分析
```
扫描文件夹 → 读取文件 → AI分析 → 生成报告 → 浏览器打开
   (1秒)      (1秒)    (2分钟)    (3秒)      (自动)
```
**总耗时**: 约 2-3 分钟

### 仅音频处理
```
读取Excel → 下载音频 → 转换MP3 → 合并输出
  (1秒)    (20秒)     (10秒)     (3秒)
```
**总耗时**: 约 30-40 秒

### 完整处理 ⭐
```
扫描文件夹 → [并行处理] → 生成结果
  (1秒)      (2-3分钟)     (自动)
              ├─ AI分析
              └─ 音频处理
```
**总耗时**: 约 2-3 分钟（并行执行）

## 🛠️ 故障排除

### 问题：找不到文件夹
**解决**: 确保文件夹在项目根目录下

### 问题：找不到录音文件
**解决**: 检查文件格式是否为 `.xlsx`/`.xls`/`.txt`

### 问题：Excel 读取失败
**解决**:
- AI分析模式：确保有F列
- 音频处理模式：确保有`segment_index`和`file_path`列

### 问题：API 调用失败
**解决**: 检查网络连接和API密钥

### 问题：下载失败
**解决**:
- 检查网络连接
- 验证音频链接是否有效
- 确认网站是否需要认证

### 问题：PDF生成失败
**解决**:
- 首次使用需运行 `playwright install chromium`
- 或在浏览器中手动按 `Ctrl+P` 保存为PDF
